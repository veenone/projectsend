# IST Professional Template

A professional business template with IST brand colors, featuring elegant design and excellent readability in both light and dark modes.

## Features

- **Professional Design**: Based on the business template with IST brand colors
- **Dark Mode Support**: Automatic color adaptation for dark mode
- **Responsive**: Works perfectly on all devices
- **IST Color Palette**: Custom color scheme matching IST branding

## Color Palette

- **Main**: #7382E6 - Primary brand color
- **Dark 1**: #323C64 - Deep navy
- **Dark 2**: #5564A5 - Medium navy
- **Light 1**: #96AFFF - Soft blue
- **Light 2**: #CDDCFF - Pale blue

## Usage

This template is automatically available in the ProjectSend themes selector.

1. Go to **Themes** in the admin menu
2. Select **IST Professional**
3. Click **Save**

## Customization

The template uses CSS custom properties (variables) for easy customization. All colors are defined in `assets/css/style.css`.
