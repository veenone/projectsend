# IST Professional System Theme

A professional business theme with IST brand colors for the admin interface, featuring elegant design and excellent readability in both light and dark modes.

## Features

- **Professional Design**: Based on the business theme with IST brand colors
- **Dark Mode Support**: Automatic color adaptation for dark mode
- **Custom Colors**: IST brand color palette throughout the interface
- **Enhanced UI**: Smooth transitions, professional shadows, and polished interactions

## Color Palette

- **Main**: #7382E6 - Primary brand color
- **Dark 1**: #323C64 - Deep navy
- **Dark 2**: #5564A5 - Medium navy
- **Light 1**: #96AFFF - Soft blue
- **Light 2**: #CDDCFF - Pale blue

## Color Behavior

- **Light Mode**: Dark text on light backgrounds for optimal readability
- **Dark Mode**: Light text on dark backgrounds with inverted color palette

## Usage

1. Go to **Themes > System Themes** or **Options > Branding**
2. Select **IST Professional System Theme** from the dropdown
3. Click **Save changes**
4. The theme will be applied immediately on the next page load

## Customization

All colors are defined using CSS custom properties in `main.css`, making it easy to customize:

```css
:root {
    --ist-main: #7382E6;
    --ist-dark-1: #323C64;
    --ist-dark-2: #5564A5;
    --ist-light-1: #96AFFF;
    --ist-light-2: #CDDCFF;
}
```
